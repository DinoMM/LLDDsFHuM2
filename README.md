Privacy Policy for EVSystem

Effective date: 27.9.2025

This Privacy Policy describes how EVSystem handles information when used by its users.

1. Information We Collect

The application does not collect any personal data such as names, emails, phone numbers, or location data.

User accounts are created manually by administrators and not through the app itself.

Locally, the application may store:

Preferences set by the user (e.g., settings, local configurations).

Values entered for help functions to improve user experience.

Users may upload data records and photos related to the business operation. These are intended solely for the internal use of the private organization.

2. Use of Data

The data collected through user input is strictly business-related and intended only for internal record-keeping and management.

Photos uploaded by users should not contain sensitive or personal data that may conflict with privacy laws.

3. Data Storage

All submitted data is stored via a private API in a secure database and file system.

Data is retained permanently unless deleted by administrators.

No data is shared with third parties unless the private company make an exception.

4. Security

Since no personal or sensitive user data is collected, there are no additional guarantees provided regarding personal data protection.

The app is intended for use in a private business environment, and access is restricted to authorized users only.

5. Children’s Privacy

The application is not directed at children under 13 (or under 16 in some jurisdictions).

As no personal information is collected, there are no special provisions for children’s data.

6. Legal Compliance

The application complies with applicable privacy regulations such as GDPR and CCPA, to the extent applicable, by ensuring no personal or sensitive user data is collected or processed.

7. User Rights

As no personal data is collected, users do not need to request deletion or correction of such data.

Any business-related records can be managed internally by the administrators of the private system.
